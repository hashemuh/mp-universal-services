MP Universal Services website
1. Replace every https://www.example.com with your real domain in: index.html, robots.txt, sitemap.xml.
2. Upload this whole folder to any static host (Netlify Drop, Cloudflare Pages, GitHub Pages).
3. Submit sitemap.xml in Google Search Console.
4. Add your street address to the JSON-LD in index.html if you want it in local search results.
